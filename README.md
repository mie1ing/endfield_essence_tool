# 基质刷取计算工具

《明日方舟：终末地》武器基质刷取优化计算工具，帮助玩家高效规划武器基质的获取路线。

## 功能特性

- **武器查询**：查询指定武器的最优刷取方案，计算覆盖武器数量
- **智能匹配**：基于基础属性三选、附加/技能属性锁定，自动计算最优刷法组合
- **覆盖去重**：同覆盖集合只保留一种方案，并剔除覆盖严格子集的方案
- **属性反查**：按基础/附加/技能属性组合筛选武器，支持部分条件匹配

## 核心逻辑概览

- **刷法枚举**：基础属性三选 + 附加/技能锁定，枚举所有可能刷法
- **覆盖计算**：统计刷法能完全匹配的武器集合
- **排序策略**：按覆盖数量降序，辅以稳定排序保证结果一致
- **覆盖去重**：相同覆盖集合去重；若某覆盖是另一覆盖的真子集，则剔除该方案

## 使用场景

- **目标武器基质定向刷取**：选择想要基质的武器，获取最优副本和刷法推荐
- **检查基质价值**：根据获得的基质词条检索是否有其适配的武器

## 安装

1. 克隆项目：
```bash
git clone https://github.com/mie1ing/endfield_essence_tool.git
cd endfield_dungeon_tool
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 项目结构

```
endfield_dungeon_tool/
├── app.py              # Streamlit 主应用
├── config.py           # 配置文件（品质、属性映射）
├── data_loader.py      # 数据加载模块
├── matcher.py          # 匹配/去重算法核心逻辑
├── requirements.txt    # 项目依赖
├── 副本.txt            # 副本数据
└── 武器.txt            # 武器数据
```

### 数据文件格式

#### 副本文件（`副本.txt`）

每行格式：`副本名称 附加属性串 技能属性串`

示例：
```
枢纽区	攻灼电寒自源终法	强压追粉巧迸流效
源石研究园	攻物电寒自暴终法	压追昂巧附医切效
```

- 属性串使用中文简称（如：攻、生、暴、强、压等）
- 每个属性串包含8个字符，代表该副本可能掉落的属性

#### 武器文件（`武器.txt`）

每行格式：`武器名称 品质 三字属性`

示例：
```
宏愿	红	敏攻附
不知归	红	意攻流
钢铁余音	金	敏物巧
```

- 三字属性依次为：基础属性+附加属性+技能属性
- 品质：红（6星）、金（5星）
