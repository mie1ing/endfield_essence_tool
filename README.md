# 基质刷取计算工具

《明日方舟：终末地》武器基质刷取优化工具，用于根据副本词条池和武器三字属性，计算更高效的刷取方案。

## 功能特性

- `武器查询`：选择一把目标武器，列出所有可刷出完全匹配基质的副本，并展示推荐刷法。
- `排除武器`：在武器查询中可排除已毕业武器，被排除的武器不会再计入覆盖武器数和覆盖列表。
- `属性反查`：按基础、附加、技能属性组合筛选武器，支持部分条件匹配。
- `多武器规划`：对多把目标武器做联合规划，输出可覆盖这些目标的策略、武器组合和对应刷法。
- `覆盖展示`：方案中展示的武器会附带三字属性，例如 `熔铸火焰（智攻夜）`。

## 界面说明

### 1. 武器查询

用于定向刷单把武器。

流程：
1. 选择目标武器。
2. 可选勾选 `排除武器`，忽略已完成武器对覆盖数的影响。
3. 查看所有可掉落该武器完全匹配基质的副本。
4. 在每个副本下查看推荐刷法表格。

表格字段：
- `基础三选`：本次刷取选择的 3 个基础属性。
- `锁定`：锁定的附加属性或技能属性。
- `覆盖武器数`：该刷法可完全匹配的武器数量。
- `覆盖武器`：该刷法覆盖的武器列表，格式为 `武器名（三字属性）`。

说明：
- 推荐结果只保留包含目标武器的方案。
- 相同覆盖集合只保留一个方案。
- 被其他方案严格包含的覆盖子集会被剔除。
- 当前每个副本默认展示前 `5` 个方案。

### 2. 属性反查

用于从词条反查武器。

流程：
1. 点击基础属性按钮。
2. 点击附加属性按钮。
3. 点击技能属性按钮。
4. 结果区会实时显示符合当前已选条件的全部武器。

说明：
- 三类属性都支持单独选择和取消选择。
- 未选择的维度不会参与过滤。
- 结果按品质、名称排序。

### 3. 多武器规划

用于同时规划多把目标武器。

输出结构：
- `已覆盖 X/Y 件目标武器`：当前可由策略覆盖的目标数量。
- `未覆盖目标`：数据中无可行刷法的目标武器。
- `策略`：覆盖当前目标集合的一种分组方式。
- `武器组合`：该组目标武器会被同一组刷法覆盖。
- 表格中的 `覆盖目标` 和 `其他武器` 均按 `武器名（三字属性）` 展示。

规划逻辑：
- 先枚举所有能覆盖至少一把目标武器的候选刷法。
- 按候选刷法能覆盖的目标集合进行分组。
- 优先把目标武器拆成最少组数。
- 对同组方案，保留同副本下覆盖结果不同的方案。
- 若某方案的 `其他武器` 覆盖严格小于另一方案，则剔除该方案。
- 最终按 `其他武器` 覆盖数量优先展示。

## 核心逻辑

### 单副本刷法枚举

每个刷法由两部分组成：
- `基础三选`
- `锁定一条附加属性或技能属性`

程序会遍历：
- 所有可能的基础属性三选组合
- 当前副本提供的全部附加属性锁定
- 当前副本提供的全部技能属性锁定

然后判断哪些武器可以在该刷法下掉落完全匹配的基质。

### 完全匹配判定

一把武器会被某刷法命中，当且仅当：
- 武器的基础属性在 `基础三选` 中
- 若锁定附加属性，则武器附加属性等于锁定值，且技能属性存在于副本技能池中
- 若锁定技能属性，则武器技能属性等于锁定值，且附加属性存在于副本附加池中

### 排序与去重

- 武器按 `品质 -> 名称` 排序。
- 单武器推荐中，刷法按 `覆盖武器数` 降序排序。
- 相同覆盖集合的方案只保留一个。
- 若一个方案的覆盖集合是真子集，则剔除该方案。

## 安装与运行

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动应用

```bash
streamlit run app.py
```

应用启动后会在本地浏览器打开。

```text
endfield_dungeon_tool/
├── app.py           # Streamlit 主应用

├── 副本.txt         # 副本数据

```

## 数据格式

### `副本.txt`

每行格式：

```text
副本名称 附加属性串 技能属性串
```

示例：

```text
枢纽区 攻灼电寒自源终法 强压追粉巧迸流效
源石研究园 攻物电寒自暴终法 压追昂巧附医切效
```

约束：
- 每行至少 3 列，允许空格或制表符分隔。
- `附加属性串` 和 `技能属性串` 中的字符不能重复。

### `武器.txt`

每行格式：

```text
武器名称 品质 三字属性
```

示例：

```text
宏愿 红 敏攻附
不知归 红 意攻流
钢铁余音 金 敏物巧
```

约束：
- 每行至少 3 列。
- `三字属性` 必须恰好为 3 个字，依次表示 `基础 + 附加 + 技能`。
- 当前品质排序为：`红` 在前，`金` 在后。
