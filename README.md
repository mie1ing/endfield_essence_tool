# 基质刷取计算工具

明日方舟：终末地游戏基质副本刷取优化计算工具，帮助玩家高效规划武器基质的获取路线。

## 功能特性

- **武器查询**：查询指定武器的最优刷取方案，计算覆盖武器数量
- **副本总览**：展示每个能量淤积点（副本）的高效刷法排名
- **智能匹配**：基于基础属性三选、附加/技能属性锁定，自动计算最优刷法组合
- **品质过滤**：支持按武器品质筛选（红、金等）
- **可视化展示**：Streamlit Web界面，武器按品质高亮显示

## 安装

1. 克隆项目：
```bash
git clone <repository-url>
cd endfield_dungeon_tool
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 使用方法

### 启动应用

```bash
streamlit run app.py
```

应用将在浏览器中自动打开（默认地址：`http://localhost:8501`）

### 数据文件格式

#### 副本文件（`副本.txt`）

每行格式：`副本名称 附加属性串 技能属性串`

示例：
```
枢纽区	攻灼电寒自源终法	强压追粉巧迸流效
源石研究园	攻物电寒自暴终法	压追昂巧附医切效
```

- 属性串使用中文简称（如：攻、生、暴、强、压等）
- 每个属性串包含8个字符，代表该副本可能掉落的属性

#### 武器文件（`武器.txt`）

每行格式：`武器名称 品质 三字属性`

示例：
```
宏愿	红	敏攻附
不知归	红	意攻流
钢铁余音	金	敏物巧
```

- 三字属性依次为：基础属性+附加属性+技能属性
- 品质：红（稀有）、金（史诗）等

## 核心算法

1. **精确掉落判定**：检查副本是否同时包含目标武器的附加属性和技能属性
2. **刷法枚举**：遍历所有基础属性三选组合（C(n,3)）和附加/技能锁定选项
3. **武器匹配**：计算每种刷法可覆盖的武器数量
4. **方案排序**：按覆盖武器数量降序排列，并去重相同覆盖集合

## 使用场景

- **目标武器定向刷取**：输入想要的武器，获取最优副本和刷法推荐
- **副本效率评估**：查看某个副本的高价值刷法，最大化单次刷取收益
- **资源规划**：通过品质过滤，聚焦于高稀有度武器的获取路线
